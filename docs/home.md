# Welcome to the flashback documentation

In this file you will find a step-by-step guide on how to setup flashback launcher!

## File names

Flashback uses a system to create game entries for every game stored in `games.json`.

All of your games need to be sorted accordingly:

`(GameProviderID) COMMON NAME [CODE (eg. for gamecube games)]`
*Note: we recommend you use GameTDB for the codes!*
https://www.gametdb.com/

All of your games should be in their own folder per console.

Example folder structure:

- `PS1/`
  - ...

- `GC/`
  - `(id: 38627) Luigi's Mansion [GLMP01].iso`
  - `The Legend of Zelda: The Wind Waker [GZLP01].iso`

- `Wii/`
  - `Mario Kart Wii [RMCP01]`

- `NX/`
  - `Splatoon 3 [CODE].nsp`
